# Lotto AI System B PRO v3.0
기존 v2의 SQLite 스키마 및 CSV 형식 유지. 공정 추첨의 예측력 향상을 주장하지 않습니다.

## 배포
1. 기존 앱에서 당첨 데이터와 생성 기록 CSV를 백업합니다.
2. ZIP 내부 파일을 기존 GitHub 저장소의 최상위에 업로드하고 Commit changes를 누릅니다. app.py 경로 유지.
3. Streamlit Cloud 로그에서 설치 완료를 확인하고 기존 주소를 새로고침합니다. 필요하면 Reboot app.
4. 데이터가 사라졌으면 당첨 데이터 CSV를 가져옵니다. 생성 기록 CSV는 별도 보관용입니다.

## 로컬 실행 및 테스트
Python 3.11 또는 3.12 권장.
`python -m pip install -r requirements.txt`
`python -m unittest discover -v`
`python -m streamlit run app.py`

## 데이터
기존 동행복권 공개 응답 주소를 사용하며 실접속은 미검증입니다. 실패하면 공식 결과를 확인하여 CSV를 가져오세요. 최초 누락 회차부터 수집하며 30회차 범위씩 처리합니다. 형식 검증은 실제 원본 일치 확인과 다릅니다. 최신 회차는 공식 사이트와 대조하세요. CSV는 draw_no,draw_date,n1,n2,n3,n4,n5,n6,bonus 열을 사용합니다. 공개 앱의 SQLite는 방문자 간 공유되며 영구 저장을 보장하지 않습니다. 개인정보를 저장하지 마세요.

## 분석
정밀 통계 탭에서 15개 항목을 선택합니다. 보너스 제외. 최근 범위는 저장된 관측 기준. 상관계수는 출현 여부의 Pearson 상관이며 비복원 추출 자체의 음의 상관에 주의합니다. 검정은 999회 모의실험으로 균등 출현 및 인접 회차 겹침 분포를 평가합니다. 모든 종류의 비무작위성을 검출하지 않으며 작은 p값은 예측력 증거가 아닙니다.

## 검증 상태
11개 단위 테스트 및 Python 컴파일 통과. Streamlit/Altair 미설치 환경에서 실제 UI, Safari, 공식 서버 연결은 미검증입니다. AI 학습 및 백테스트는 포함하지 않습니다.
